MOVEit Transfer mass exploitation (CVE-2023-34362)

From late May 2023, attackers abused a previously unknown SQL injection flaw (CVE-2023-34362) in Progress MOVEit Transfer, a file transfer app that sits on the internet. They planted a web shell called LEMURLOOT and stole stored files at scale before a fix existed. CISA and FBI tie the campaign to the CL0P ransomware gang (TA505), which then pressed victims through its leak site. Thousands of organizations were hit, many through vendors that used MOVEit.

Attack flow

or use ← →

  1. 1 Abuse an unknown SQL injection flaw over the web

    Initial Access T1190

    Attackers attributed to CL0P (TA505) → MOVEit Transfer web app (internet-facing)

    From about 27 May 2023 the attackers sent crafted web requests to MOVEit Transfer servers exposed to the internet. A flaw in the web app let them, without logging in, mix their own database instructions into the queries the app sends to its database. No fix existed yet, so every exposed version was open. Progress published its advisory on 31 May 2023.

    Sources: [1] [2] [3] [4]

  2. 2 Turn database access into admin-level control

    Privilege Escalation Reported

    MOVEit Transfer web app (internet-facing) → MOVEit Transfer database

    Progress and the CVE record confirm the flaw let an outsider learn the layout and contents of the MOVEit database and change or delete records. Huntress, which rebuilt the attack, reports that this was used to get administrator-level access inside the app. That second part comes from research, not from the vendor.

    Sources: [1] [2] [5]

  3. 3 Make the server run attacker code

    Execution Reported

    MOVEit Transfer web app (internet-facing) → MOVEit Transfer Windows server

    Huntress reports that the admin-level access was then used to make the server run the attackers' own code, under a service account with local administrator rights. The vendor advisory does not describe this chain. CISA and FBI only confirm that the attackers went on to install files on the server.

    Sources: [5] [3]

  4. 4 Plant the LEMURLOOT web shell

    Persistence T1505.003

    Attackers attributed to CL0P (TA505) → MOVEit Transfer Windows server

    The attackers dropped a web shell, a hidden web page that takes their commands, named human2.aspx so it looked like the real MOVEit file human.aspx. CISA and FBI call it LEMURLOOT. It only answered requests that carried a secret password, so the attackers kept sole use of it.

    Sources: [3] [4] [1]

  5. 5 Add a fake 'Health Check Service' admin account

    Persistence T1136

    MOVEit Transfer Windows server → MOVEit Transfer database

    Through the web shell the attackers could add a MOVEit administrator with a random username and the display name Health Check Service, and could delete such accounts again. CISA warns these accounts live in the database, so a rebuilt server that reuses the old database can still hold them.

    Sources: [3] [4]

  6. 6 List the database, files and folders

    Discovery

    MOVEit Transfer Windows server → MOVEit Transfer database

    The web shell could list the contents of the underlying database and the files and folders stored in MOVEit, and fetch a file by its name. This showed the attackers what each victim held.

    Sources: [3] [4]

  7. 7 Read Azure Blob Storage settings and keys

    Credential Access

    MOVEit Transfer Windows server → Linked Azure Blob Storage

    On servers that keep files in Microsoft Azure, the web shell could read the app settings that hold the storage account details and access key. Mandiant warns this may have let the attackers take files straight from Azure as well.

    Sources: [3] [4] [1]

  8. 8 Download stored files in bulk

    Exfiltration T1041

    MOVEit Transfer Windows server → Attackers attributed to CL0P (TA505)

    The attackers pulled out files that users had uploaded to MOVEit, sent back through the web shell in compressed form. Mandiant saw large amounts taken, sometimes within minutes of the web shell going in. Rapid7 found data theft going back to at least 28 May 2023.

    Sources: [3] [4] [6]

  9. 9 Pressure victims through the CL0P leak site

    Impact Reported

    Attackers attributed to CL0P (TA505) → MOVEit customers and people in their files

    On 6 June 2023 a post on the CL0P leak site claimed the attacks and told victims to get in touch by 14 June or see their data published. CISA and FBI say CL0P now mostly steals data to extort rather than encrypting it. Mandiant links the activity to the FIN11 group, and Rapid7 notes Microsoft tied it to Lace Tempest.

    Sources: [4] [6] [3]

Impact

Files were stolen from MOVEit servers in many sectors and countries, led by the United States and Canada, with education, health and finance hit hardest. Many organizations were exposed only through a vendor or contractor that ran MOVEit. Emsisoft's tally from breach notices, filings and the leak site reached 2,773 organizations and about 95.8 million people by June 2024, though some people are counted more than once.

Sources: [7] [4]
